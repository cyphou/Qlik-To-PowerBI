## Executable Tools

### Local Parity Enforcement

**Tool:** [`tools/analysis/parity_status_check.py`](../../tools/analysis/parity_status_check.py)

```bash
py -3 tools/analysis/parity_status_check.py
```

**Purpose:** Validate local consistency (versions, modules, flags, documentation)  
**Exit code:** 0 (pass) or 1 (fail)  
**Frequency:** Every commit (via CI/CD)

**Checks performed:**
1. Version alignment (all modules at v12.0.0)
2. Required modules present (13/13)
3. Required flags wired (10/10)
4. Documentation consistency (links, versions)

---

### Upstream Parity Measurement

**Tool:** [`tools/analysis/agent_feature_parity_check.py`](../../tools/analysis/agent_feature_parity_check.py)

```bash
# Measure upstream parity
py -3 tools/analysis/agent_feature_parity_check.py \
  --upstream-path "C:/GitHub Project/TableauToPowerBI"

# Output as JSON (for automation)
py -3 tools/analysis/agent_feature_parity_check.py \
  --upstream-path "C:/GitHub Project/TableauToPowerBI" \
  --json
```

**Purpose:** Compare local agent/feature inventory with upstream  
**Exit code:** 0 (always succeeds unless `--strict-upstream` flag used)  
**Frequency:** On-demand (can be scheduled in CI)

**Scoring formula:**
```
score = (agents_present / 15) × 0.5
      + (modules_present / 13) × 0.3
      + (flags_wired / 10) × 0.2
```

## Reference

### Command Reference

```bash
# Local parity check
py -3 tools/analysis/parity_status_check.py

# Upstream parity check (local path)
py -3 tools/analysis/agent_feature_parity_check.py \
  --upstream-path "C:/path/to/TableauToPowerBI"

# Upstream parity check (GitHub repository)
py -3 tools/analysis/agent_feature_parity_check.py \
  --upstream-repo cyphou/QlikToPowerBI \
  --branch main

# Multiple candidates (default: 5 repos)
py -3 tools/analysis/agent_feature_parity_check.py \
  --scan-default-candidates

# JSON output for automation
py -3 tools/analysis/agent_feature_parity_check.py \
  --upstream-path . \
  --json > parity_result.json

# Strict mode (fail if upstream not at parity)
py -3 tools/analysis/agent_feature_parity_check.py \
  --upstream-path . \
  --strict-upstream
```
